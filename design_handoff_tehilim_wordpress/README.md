# Handoff: "תהילים" — פלטפורמת קמפייני תהילים קהילתיים (WordPress Theme)

> מסמך זה נכתב עבור מפתח/ת שמשתמש/ת ב‑Claude Code כדי לבנות **תבנית (theme) לוורדפרס** מתוך עיצוב קיים.
> קראו אותו במלואו לפני שמתחילים. הוא מיועד להיות **עצמאי** — אפשר לממש את כל האתר מהמסמך הזה בלבד.

---

## 1. סקירה כללית (Overview)

"תהילים" היא פלטפורמה קהילתית ליצירת **קמפיינים של אמירת תהילים** — לרפואה, לישועה, לזיווג, לעילוי נשמה ולכל מטרה. משתמש פותח קמפיין, מגדיר יעד (מספר ספרי תהילים), מזמין **שגרירים** שכל אחד מגייס את החוג שלו, וכולם עוקבים בזמן אמת אחרי כמות הפרקים/הספרים שהושלמו. המבנה דומה לפלטפורמת גיוס המונים (crowdfunding) — רק ש"התרומה" היא אמירת פרקי תהילים.

**קהל יעד:** דוברי עברית, שומרי מצוות. האתר **RTL** לחלוטין, בעברית.

**חשוב:** האתר בנוי בוורדפרס והתוצר צריך להיות **תבנית וורדפרס** שניתן להתקין באתר קיים.

## 2. על קבצי העיצוב (About the Design Files)

### ⭐ מקור האמת: תיקיית `static-html/`
**התחילו כאן.** בתיקייה `static-html/` נמצאים **ששה קבצי HTML עצמאיים** — שחזור מדויק ומרונדר של כל עמוד בעיצוב, כ‑HTML/CSS נקי עם inline styles וללא שום runtime. פותחים כל קובץ בדפדפן ורואים בדיוק את העיצוב הסופי. **אלה הקבצים לבנות מהם את התבנית** — כל המרקאפ, המרווחים, הצבעים, הצללים והטקסט כבר שם, מוכנים להמרה ל‑PHP templates. אל תנחשו — העתיקו את המבנה מהם 1:1.

- `static-html/index.html` — אינדקס עם קישור לכל עמוד.
- `static-html/home.html` · `archive.html` · `campaign.html` · `ambassador-public.html` · `ambassador-dashboard.html` · `create.html`
- `static-html/fonts/` — הפונט Asimon (כבר מקושר ב‑`@font-face` בכל קובץ).
- **מעברי hover** נשמרו כ־`data-hover-style` / `data-active-style` על האלמנטים → יש להמיר ל־`:hover`/`:active` ב‑CSS של התבנית.
- **אזורי תמונה** מסומנים ב־`data-image-slot` → בוורדפרס = featured image.
- הכפתורים בקבצים הסטטיים אינם מקושרים (רפרנס ויזואלי); ההתנהגות מתועדת בסעיף 6.

### קובץ אב‑הטיפוס האינטראקטיבי (משני)
הקבצים ב‑`design-reference/` הם **אב‑הטיפוס האינטראקטיבי המקורי** — שימושי כדי לראות את המעברים, הניווט בין המסכים והאינטראקציות פועלים (פותחים את `design-reference/תהילים יחד - דסקטופ.dc.html` בדפדפן). זהו פורמט תבנית עם runtime — הם מדגימים את המראה, ההתנהגות והתוכן הרצויים, אבל **הם אינם קוד production להעתקה ישירה**. המשימה היא **לשחזר את העיצוב הזה בתוך סביבת וורדפרס** (PHP templates, custom post types, טקסונומיות, enqueue של נכסים) לפי המוסכמות של וורדפרס — ולא לשפוך את ה‑HTML כמו שהוא.

### פורמט קובץ העיצוב
קובץ העיצוב הראשי הוא `design-reference/תהילים יחד - דסקטופ.dc.html`. זהו "Design Component" — HTML עם תחביר תבניות קל:
- `{{ something }}` = **חור נתונים** (data hole) — ערך שמוזרק מהלוגיקה. בוורדפרס זה הופך ל‑PHP echo / שדה ACF / לולאה.
- `<sc-for list="{{ items }}" as="x">…</sc-for>` = **לולאה**. בוורדפרס → `WP_Query` / `foreach`.
- `<sc-if value="{{ flag }}">…</sc-if>` = **תנאי**. בוורדפרס → `if`.
- כל ה‑CSS הוא **inline styles** על האלמנטים. הצבעים/מרווחים/פונטים המדויקים נמצאים שם — זה מקור האמת לסגנון.
- ה"מסכים" (home / archive / campaign / ambassador / dashboard / create) מתחלפים ב‑`isHome`, `isCampaign` וכו'. **בוורדפרס כל מסך הוא template נפרד** (ראו מיפוי בהמשך) — אין כאן SPA.

> לבנייה בפועל השתמשו ב‑`static-html/` (מקור האמת). אב‑הטיפוס האינטראקטיבי הוא רק להבנת ההתנהגות והמעברים.

## 4. סטאק וארכיטקטורת וורדפרס מומלצת

**Theme קלאסי (PHP templates)** — לא בלוקים/FSE, אלא אם המפתח מעדיף. הצעה למבנה:

```
tehilim-theme/
├── style.css              # header של התבנית + טוקנים גלובליים
├── functions.php          # enqueue, CPTs, taxonomies, rewrite, AJAX/REST
├── header.php             # <head> + סרגל ניווט (Nav)
├── footer.php             # Footer
├── front-page.php         # מסך הבית (Home)
├── archive-campaign.php   # ארכיון כל הקמפיינים + סינון לפי מטרה
├── single-campaign.php    # עמוד קמפיין בודד (הרו, מד התקדמות, קורא תהילים, שגרירים, פיד, sidebar שיתוף)
├── template-ambassador.php# עמוד שגריר ציבורי (הקישור שהשגריר מפיץ)
├── template-dashboard.php # אזור אישי פרטי של שגריר
├── page-create.php        # טופס פתיחת קמפיין
├── assets/
│   ├── fonts/             # Asimon (ראו סעיף Assets + רישוי)
│   ├── css/theme.css      # אם מוציאים את ה‑inline styles לקובץ
│   └── js/app.js          # קורא התהילים, "סימנתי שאמרתי", העתקת לינק, אקורדיון FAQ, קרוסלה
└── inc/
    ├── cpt.php            # רישום post types + taxonomy
    ├── meta.php           # שדות meta (או ACF)
    └── ajax.php           # endpoints ל"סימנתי שאמרתי" ולנתונים חיים
```

### מודל נתונים (Data Model)

**Custom Post Type `campaign`:**
- `post_title` — שם ההקדשה (למשל "משה בן חיה")
- meta `dedication` — סוג ההקדשה: `לרפואת` / `לעילוי נשמת` / `לזיווג` / `לפרנסת` / `לזכות` / `לרגל`
- taxonomy `occasion` — מטרה: `refua` (רפואה שלמה), `iluy` (עילוי נשמה), `zivug` (זיווג הגון), `parnasa` (פרנסה טובה), `zchut` (זכות והצלחה), `event` (שמחה ואירוע)
- meta `goal_books` (int) — יעד בספרי תהילים (ספר שלם = 150 פרקים)
- featured image — תמונת הקמפיין (בהרו יש אזור תמונה)
- מחושבים: `books_done`, `chapters_done` (מ‑recitations), `participants_count`, `pct = round(books_done/goal_books*100)`

**Custom Post Type `ambassador`** (שייך לקמפיין):
- `post_title` — שם השגריר
- meta `campaign_id` (relation), `goal_chapters` (int), `recited_chapters` (int), `via_count` (כמה נכנסו דרכו), `avatar_color`, `slug`
- קישור אישי ציבורי: `/c/{campaign-slug}/{ambassador-slug}` (rewrite rule)

**Custom table `wp_tehilim_recitations`** (או postmeta מצטבר) — לתיעוד אמירות:
`id, campaign_id, ambassador_id (nullable), chapter_number, reciter_name (nullable), created_at`.
כל "סימנתי שאמרתי" מוסיף שורה, מגדיל מונים, ומקצה לקורא פרק חדש. ניתן לרענן "בזמן אמת" ע"י polling ל‑REST endpoint כל כמה שניות.

**טקסט התהילים:** 150 פרקים **מנוקדים**. באב‑הטיפוס יש רק 3 פרקים לדוגמה (ק׳, קכ״א, כ״ג). יש להביא את הטקסט המלא — מקור מומלץ: **Sefaria API** (רישיון CC) או קובץ JSON מנוקד. שמרו כ‑`tehilim.json` (מערך של {chapter, verses:[{n,t}]}) או כ‑CPT. הטקסט עצמו נחלת הכלל.

### פעולות דינמיות
- **"סימנתי שאמרתי"** → AJAX/REST: מוסיף אמירה, מגדיל מונה קמפיין + מונה שגריר (אם הגיעו דרך שגריר), מחזיר את הפרק הבא. ללא צורך בהרשמה (שם אופציונלי).
- **פתיחת קמפיין** (טופס Create) → יצירת `campaign` (טיוטה/ממתין לאישור, לבחירתכם).
- **הצטרפות כשגריר** → יצירת `ambassador` הממתין לאישור בעל הקמפיין.
- **שיתוף** → כפתור WhatsApp (`https://wa.me/?text=...`) + העתקת לינק (clipboard).

## 5. מסכים / Views

לכל מסך: מטרה, פריסה, רכיבים, קופי מדויק. הצבעים/פונטים המדויקים בסעיף Tokens (סעיף 8).

### 5.0 גלובלי — סרגל ניווט (header.php)
- Sticky עליון, רקע `rgba(250,244,234,.88)` + `backdrop-filter: blur(10px)`, גבול תחתון `#EADCC6`, גובה 74px, `max-width:1200px` ממורכז, `padding:0 32px`.
- **ימין (בגלל RTL — התחלה):** לוגו = ריבוע מעוגל 42px בגרדיאנט `linear-gradient(140deg,#C86A45,#A5442A)` עם אייקון **ספר פתוח** (SVG, קו קרם `#FFF3E4` + שדרה בזהב `#F0CE7E`) + wordmark **"תהילים"** (Asimon 800, 23px, `#2E2318`).
- **מרכז:** קישורים "איך זה עובד" · "קמפיינים" · "אודות" (`#6B5D4C`, 15.5px, 600). **נעלמים מתחת ל‑900px.**
- **שמאל:** כפתור "התחברות" (מסגרת) + כפתור ראשי "צור קמפיין" (גרדיאנט `#C05A3A→#A94B2E`, לבן).

### 5.1 מסך הבית (front-page.php)
מטרה: להסביר את הרעיון ולהניע לפתיחת קמפיין / גילוי קמפיינים.
סקשנים לפי הסדר:
1. **הרו (א‑סימטרי, 2 טורים, `grid-template-columns:1.02fr .98fr`):**
   - **ימין:** כותרת H1 בשלוש שורות — "מתאחדים סביב / קריאת תהילים משותפת / **לברכה, לרפואה ולישועה**" (השורה השלישית בטרקוטה `#B24328`). תת‑כותרת: "בחרו מטרה, הזמינו שגרירים ועקבו בזמן אמת אחרי כל פרק — עד שהקהילה כולה משלימה יחד אלפי פרקי תהילים." שני כפתורים: "צרו קמפיין" (ראשי, עם חץ) + "גלו קמפיינים" (ghost). שורת הוכחה חברתית: 4 אווטארים חופפים + "כבר **4,280** אומרים תהילים ב־**128** קמפיינים".
   - **שמאל:** **כרטיס קמפיין "חי"** מוגבה — אווטאר "מ" + "משה בן חיה" + "קמפיין לזיווג הגון" + תגית ירוקה "שידור חי"; **טבעת התקדמות** conic 30%; מיני‑סטטיסטיקות (ספרים 3/10, פרקים 46,800, משתתפים 87); שורת אווטארי שגרירים. **צ'יפים צפים** סביב הכרטיס: ירוק "פרק ק״ג הושלם · לפני רגע" + כהה "מובילה: ריקי לוי · 210 פרקים". רקעים: זוהר זהב רך + טבעות קונצנטריות דהויות (SVG).
2. **רצועת סטטיסטיקות** — שורה אחת עם 4 מספרים ומפרידים אנכיים: 4,280 משתתפים | 46,800 פרקי תהילים נאמרו | 312 ספרים הושלמו | 128 קמפיינים פעילים. הופכת ל‑2×2 במובייל.
3. **"קמפיינים שעלו לאחרונה"** — כותרת + תת‑כותרת "הצטרפו לקהילות שכבר התחילו לומר תהילים יחד." + גריד 3 כרטיסי קמפיין (ראו רכיב "כרטיס קמפיין" בסעיף 5.2) + כפתור "לכל הקמפיינים".
4. **"איך זה עובד?"** — 3 כרטיסים ממוספרים 01/02/03: "פותחים קמפיין" · "מזמינים שגרירים" · "עוקבים בזמן אמת".
5. **"כל מה שצריך לקמפיין מנצח"** — גריד 4×2 של 8 כרטיסי תכונה (אייקון + כותרת + תיאור).
6. **"מעלת אמירת תהילים יחד!"** — תת‑כותרת "מדברי חז״ל וגדולי ישראל בשבח מעלת אמירת התהילים." + קרוסלה של **ציטוטים מחז"ל וגדולי ישראל** (3 בכל עמוד, כפתורי הבא/הקודם). התוכן המלא בסעיף 7.
7. **שאלות נפוצות** — אקורדיון (7 שאלות, אחת פתוחה בכל רגע). התוכן בסעיף 7.
8. **באנר CTA כהה (א‑סימטרי):** רקע espresso עם זוהר זהב + watermark של ספר + טבעת; ימין: תג "חינם · ללא הרשמה · תוך דקות", כותרת "צרו קמפיין תהילים **משלכם**", כפתור ראשי + ghost "גלו קמפיינים קיימים" + שורת אווטארים; שמאל: כרטיס זכוכית עם טבעת 30%.
9. **Footer** (ראו 5.6).

### 5.2 ארכיון הקמפיינים (archive-campaign.php)
מטרה: לגלות את כל הקמפיינים ולסנן.
- כותרת "כל הקמפיינים" + תג "ארכיון הקמפיינים" + מונה "{N} קמפיינים".
- **שורת צ'יפים לסינון לפי מטרה:** הכל · רפואה שלמה · עילוי נשמה · זיווג · פרנסה · זכות · שמחה. הצ'יפ הפעיל במילוי טרקוטה. (בוורדפרס → סינון taxonomy `occasion`, אפשר AJAX או query var.)
- **גריד 3 טורים של "כרטיס קמפיין".**

**רכיב "כרטיס קמפיין" (חוזר בבית ובארכיון):** כרטיס לבן `#FFFFFF`, radius 24px, צל רך, **hover מרים 5px**. חלק עליון = גרדיאנט עדין (משתנה לפי כרטיס). גוף: שם (800/21px) → "מוקדש · {סוג}" (muted) → שם המטרה (`#6B5D4C`). שורה: אייקון ספר + "{done} / {goal}" (מימין) + **צ'יפ סטטוס** (משמאל): זהב "בעיצומו · {pct}%" עם אייקון להבה, או ירוק "כמעט הושלם/הושלם · {pct}%" עם וי כש‑pct≥80. פס התקדמות דק (מילוי משמאל, רוחב = pct) מעל "ספרים הושלמו". כפתור "כניסה לקמפיין" (מסגרת) עם חץ.

### 5.3 עמוד קמפיין בודד (single-campaign.php)
מטרה: לומר תהילים ולעקוב.
- **הרו:** תג המטרה, H1 = שם ההקדשה (52px), "מוקדש לזכות", תיאור, ואזור תמונת קמפיין (460×280, `image‑slot` באב‑טיפוס → featured image בוורדפרס).
- **גריד 2 טורים `1fr 336px`:**
  - **טור ראשי:** (א) כרטיס **מד התקדמות** — אחוז ענק 30%, פס, 4 מיני‑סטטיסטיקות (ספרים/פרקים/משתתפים/שגרירים). (ב) **קורא תהילים** — כותרת הפרק, טקסט מנוקד (**פונט Frank Ruhl Libre serif**), שדה שם (אופציונלי), כפתורי "פרק אחר"/"פרק רנדומלי" ו‑**"סימנתי שאמרתי"** (מפעיל AJAX + טוסט אישור). (ג) באנר "הצטרפו כשגריר/ה". (ד) "השגרירים שלנו" — רשימת שגרירים עם דירוג + פס אישי; **לחיצה פותחת את עמוד השגריר** (5.4). (ה) "פעילות אחרונה" — פיד.
  - **Sidebar (sticky, נעשה static מתחת 900px):** כרטיס שיתוף (WhatsApp + העתקת לינק) + כרטיס "לוח שגרירים".

### 5.4 עמוד שגריר ציבורי (template-ambassador.php) — הקישור שהשגריר מפיץ
מטרה: מבקר שנכנס דרך הקישור האישי של שגריר — כל פרק שיאמר נזקף **לזכות אותו שגריר**.
- **הרו מותאם אישית:** תג "הוזמנתם על ידי שגריר/ה בקמפיין", אווטאר + שם השגריר + "מזמין/ה אתכם להצטרף", "לקמפיין התהילים למען **משה בן חיה** — לזיווג הגון", "כל פרק שתאמרו כאן נזקף לזכות היעד של {שם} בקמפיין." כפתורים: "הצטרפו ואמרו תהילים" + "שתפו הלאה". מימין: **כרטיס טבעת אישית** — "היעד האישי של {שם}", טבעת conic עם אחוז חי, "{recited} / {goal} פרקים · גויסו על ידי {שם}".
- מתחת: 3 סטטיסטיקות אישיות (פרקים גויסו · אמרו דרכי · מקום בדירוג) → קורא תהילים (זהה ל‑5.3 אבל האמירות נזקפות לשגריר) → כרטיס "התמונה הגדולה · הקמפיין כולו" → Sidebar: "שתפו את הקישור של {שם}" (מציג `tehilim.co/c/moshe/{slug}`) + לוח שגרירים שמדגיש את השגריר הנוכחי.

### 5.5 אזור אישי של שגריר (template-dashboard.php)
תצוגה פרטית: טבעת אחוז, סטטיסטיקות (פרקים גויסו / אמרו דרכי / מקום בדירוג), הקישור האישי + כפתור העתקה, וכפתור "צפו בעמוד ההפצה שלכם" (פותח את 5.4).

### 5.6 טופס פתיחת קמפיין (page-create.php)
כותרת "פתיחת קמפיין תהילים". שדות: בחירת מטרה (צ'יפים), "שם לרפואה / לזכות" (input), "שם המארגן / הקבוצה" (input), **בורר יעד** (slider 1–100 ספרים, מציג "{n} ספרי תהילים · {n×150} פרקים"), כפתור "יצירת הקמפיין".

### 5.7 Footer
4 טורים (`2fr 1fr 1fr 1fr`): לוגו + תיאור + תג "נבנה באהבה לעם ישראל"; "המוצר" (גלו קמפיינים / פתחו קמפיין / האזור שלי); "אודות"; "משאבים". שורת זכויות: "© 2026 תהילים · כל הזכויות שמורות."

## 6. אינטראקציות, אנימציות והתנהגות רספונסיבית

- **Hover:** מעברים 160–220ms ease על כל כפתור/קישור/כרטיס. כפתורים ראשיים מתרוממים (`translateY(-1..-2px)`), כרטיסי קמפיין מתרוממים 5px עם צל חזק יותר, קישורי ניווט מתחלפים לצבע המותג.
- **Click feedback:** כל כפתור מתכווץ בלחיצה (`:active { transform: scale(.96) }`).
- **Focus (נגישות):** `:focus-visible { outline: 2px solid #A94B2E; outline-offset: 2px }` על כפתורים/קישורים/inputs. inputs מקבלים טבעת focus רכה.
- **כניסה (entrance):** כל מסך נכנס ב‑`floatIn` — opacity 0→1 + `translateY(14px)→0`, משך .55s, easing `cubic-bezier(.2,.7,.2,1)`.
- **`prefers-reduced-motion: reduce`** — מכבה אנימציות/מעברים. **חובה לשמר.**
- **טבעת התקדמות:** `conic-gradient(#E9B75A 0deg, #C05A3A {deg}deg, #EFE3CF {deg}deg)` כאשר `deg = pct * 3.6`.
- **פס התקדמות:** track `#EFE3CF`, מילוי `linear-gradient(90deg,#C05A3A,#D9A441)` ברוחב = pct, מעוגן משמאל.
- **קורא התהילים:** "סימנתי שאמרתי" → טוסט אישור זמני ("נרשם! תודה — קיבלתם פרק חדש") + טעינת פרק חדש. **ללא אימוג'ים כאייקונים** (השתמשו ב‑SVG בלבד — Heroicons/Lucide בסגנון).
- **אקורדיון FAQ:** פריט אחד פתוח בכל רגע, חץ שמסתובב 180°.
- **קרוסלת ציטוטים:** 3 בכל עמוד, ניווט הבא/הקודם.

### נקודות שבירה רספונסיביות (מיושמות באב‑הטיפוס)
- **≤1024px:** גרידים של 4 ו‑3 → 2 טורים; Footer → 2 טורים.
- **≤900px:** הרו/קמפיין/שגריר → טור אחד; sidebar עוצר sticky והופך לרוחב מלא; תמונות/כרטיסים בעלי רוחב קבוע → 100%; קישורי הניווט המרכזיים נעלמים (הוסיפו תפריט המבורגר); כותרות ענק קטנות (52→36); רצועת הסטטיסטיקות → 2×2.
- **≤620px:** כל גרידי הכרטיסים → טור אחד; מרווחי צד מצומצמים.

### ציטוטים — סקשן "מעלת אמירת תהילים יחד!"
> יש לוודא נאמנות למקור לפני פרסום. אלה הנוסחים באב‑הטיפוס (תמצית/פרפרזה של תורות ידועות):
1. "כל הקורא בספר תהילים — מעלה עליו הכתוב כאילו עוסק בכל התורה כולה." — **מדרש שוחר טוב**, מדרש תהילים מזמור א׳
2. "אם היו יודעים בני אדם את מעלת אמירת תהילים — היו אומרים אותם בכל עת ובכל שעה." — **רבי נחמן מברסלב**, ליקוטי מוהר״ן
3. "אין לך דבר המעורר את רחמי שמים כאמירת תהילים בציבור מתוך לב שלם." — **החפץ חיים**, ר׳ ישראל מאיר הכהן זצ״ל
4. "דוד המלך שיבח וזימר עד ששרתה עליו רוח הקודש — וכל האומר תהיליו מעורר בנפשו קדושה." — **הזוהר הקדוש**, תורת הסוד
5. "אמירת תהילים מסוגלת לבטל גזירות קשות ולהמשיך ישועה, רפואה וברכה לאומריה." — **רבי חיים פלאג׳י**, כף החיים
6. "כשרבים מתאחדים באמירת תהילים — כוח תפילתם בוקע רקיעים ומקרב את הישועה." — **חכמינו ז״ל**, מעלת התפילה בציבור

### שאלות נפוצות
1. האם השימוש בפלטפורמה כרוך בתשלום? — לא. הפלטפורמה חינמית לחלוטין, ללא מטרות רווח.
2. האם זה עוד אתר לקריאת תהילים? — זו פלטפורמה לניהול קמפיינים קהילתיים סביב אמירת תהילים — עם יעדים, שגרירים ומעקב בזמן אמת.
3. איך נספרים הפרקים? — כל פרק שמשתתף מסמן כ"נאמר" נספר לקמפיין וגם לשגריר שדרכו נכנס.
4. מהו תפקיד השגריר? — שגריר לוקח יעד אישי, מקבל קישור משלו, ומגייס דרכו אנשים נוספים.
5. האם ניתן לשתף את הקמפיין? — כן, בלחיצה אחת בוואטסאפ / העתקת קישור.
6. כמה זמן לוקח לפתוח קמפיין? — פחות מדקה.
7. האם הנתונים שלי מאובטחים? — כן, ללא דרישת פרטים רגישים.
